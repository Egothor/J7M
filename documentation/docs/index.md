<section class="j7m-home-lineage" markdown>
## From j5m to J7M

J7M builds on **j5m**, an earlier version of the middleware developed for a
**high-capacity crawler and a virtual army**. J7M continues that foundation and
serves as the middleware base for new versions of related projects implemented
as distributed applications.
